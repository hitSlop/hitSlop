# Eisenhower Matrix

A paper desk blotter for sorting work into Do First, Schedule, Delegate, and Don’t Do, with a triage holding pen and a live Q2 leverage ratio.

From the repository root:

```sh
bun slop dev examples/slops/eisenhower-matrix
bun slop build examples/slops/eisenhower-matrix
bun slop register examples/slops/eisenhower-matrix
```

Create a writable copy of the registered template before editing.
