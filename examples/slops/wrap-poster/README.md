# Wrap Poster

An editorial poster where the text flows around shapes you drag. Layout uses [Pretext](https://github.com/chenglou/pretext) (MIT) to measure and break lines without touching the DOM; the typeface is Lora (SIL OFL).

From the repository root:

```sh
bun slop dev examples/slops/wrap-poster
bun slop build examples/slops/wrap-poster
bun slop register examples/slops/wrap-poster
```

Create a writable copy of the registered template before editing.
