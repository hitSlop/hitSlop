# Beat Pad

A 16-step drum and bass sequencer. Tap steps, choose a kit, set tempo and swing; the pattern is saved with the document. Sound comes from [Tone.js](https://tonejs.github.io) (MIT), loaded only when you press Play.

From the repository root:

```sh
bun slop dev examples/slops/beat-pad
bun slop build examples/slops/beat-pad
bun slop register examples/slops/beat-pad
```

Create a writable copy of the registered template before editing.
