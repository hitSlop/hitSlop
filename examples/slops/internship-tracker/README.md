# Internship Tracker

A conference name badge for moving applications from wishlist to offer, with follow-up dates and a coffee-chat log.

From the repository root:

```sh
bun slop dev examples/slops/internship-tracker
bun slop build examples/slops/internship-tracker
bun slop register examples/slops/internship-tracker
```

Create a writable copy of the registered template before editing.
