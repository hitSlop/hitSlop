# Internship Tracker design

One job: see where every application stands and which one needs a nudge next.

The object is a conference name badge hanging from a navy lanyard. A vermilion
band reads "Hello, I'm applying to" above a hand-lettered search title. Each
application carries a rotated ink stamp for its stage; stage colors are
reinforced by the stamp word, never color alone. A six-segment tally under the
title shows the pipeline, and a follow-up chip turns red with the word
"overdue" or "due today". A second tab logs coffee chats with a thank-you check.

System Avenir/Helvetica for text and Marker Felt/Bradley Hand for the
title. Bits UI owns tabs and the stage select. The export is the badge alone
with no controls. The icon is the badge: slot, band and three stamped rows.
