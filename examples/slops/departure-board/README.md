# Departure Board

Your day as a split-flap airport board. Tap a row to change its status, edit the stops, and turn on the clack if you like. Built with GSAP (free under the GSAP Standard License); the font is Space Mono (SIL OFL).

From the repository root:

```sh
bun slop dev examples/slops/departure-board
bun slop build examples/slops/departure-board
bun slop register examples/slops/departure-board
```

Create a writable copy of the registered template before editing.
