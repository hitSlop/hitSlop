# MASH

The sleepover fortune game on a notebook page. Fill in your possible futures, draw the spiral, and let the count decide where you live, who you marry and what you drive.

From the repository root:

```sh
bun slop dev examples/slops/mash
bun slop build examples/slops/mash
bun slop register examples/slops/mash
```

Create a writable copy of the registered template before editing.
