# Tiny Planet

A low-poly world to spin and decorate. Plant trees, build houses, drop rocks and crystals, switch the season, or roll a new world. Built with three.js; the document saves only the world's seed, the season and where each thing stands.

From the repository root:

```sh
bun slop dev examples/slops/tiny-planet
bun slop build examples/slops/tiny-planet
bun slop register examples/slops/tiny-planet
```

Create a writable copy of the registered template before editing.
