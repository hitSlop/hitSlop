# Project Pan

A rose-gold compact for using up your makeup and skincare before buying more. Each pan hollows out as you use it, with period-after-opening dates and a shelf for empties.

From the repository root:

```sh
bun slop dev examples/slops/project-pan
bun slop build examples/slops/project-pan
bun slop register examples/slops/project-pan
```

Create a writable copy of the registered template before editing.
