# Paycheck Flow

See where one month of income goes. Money in flows through a single hub into spending buckets, with what is left over in gold, or a red "over budget" source when spending is more than income. Built with [Layer Cake](https://layercake.graphics) (MIT) for the chart layers and d3-sankey (BSD-3-Clause) for the ribbons.

From the repository root:

```sh
bun slop dev examples/slops/paycheck-flow
bun slop build examples/slops/paycheck-flow
bun slop register examples/slops/paycheck-flow
```

Create a writable copy of the registered template before editing.
