# Scratch-Off List

A lottery-ticket bucket list. Scratch the silver foil to reveal your next adventure, stamp it done, and export the card.

From the repository root:

```sh
bun slop dev examples/slops/scratch-off-list
bun slop build examples/slops/scratch-off-list
bun slop register examples/slops/scratch-off-list
```

Create a writable copy of the registered template before editing.
