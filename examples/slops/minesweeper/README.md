# Buoy Sweep

Minesweeper on a harbor chart. Tap water to clear it, flag mines with buoys, and beat your best time. The board and clock resume when you reopen the document.

From the repository root:

```sh
bun slop dev examples/slops/minesweeper
bun slop build examples/slops/minesweeper
bun slop register examples/slops/minesweeper
```

Create a writable copy of the registered template before editing.
