# Household Chores

A fridge-door chore wheel for roommates, families and kids. Assign chores to people, tick them off, rotate assignments each week and keep the points fair.

From the repository root:

```sh
bun slop dev examples/slops/household-chores
bun slop build examples/slops/household-chores
bun slop register examples/slops/household-chores
```

Create a writable copy of the registered template before editing.
