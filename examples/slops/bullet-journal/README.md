# Bullet Journal

Ryder Carroll’s analog rapid logging on cream dot-grid paper: tasks, events, notes, and classic signifier transitions.

From the repository root:

```sh
bun slop dev examples/slops/bullet-journal
bun slop build examples/slops/bullet-journal
bun slop register examples/slops/bullet-journal
```

Create a writable copy of the registered template before editing.
