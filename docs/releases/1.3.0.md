# hitSlop 1.3.0

## Mac app

No Mac app changes in this release.

## iPhone app

### Improved

- Open `.slop` files from Files and AirDrop directly in hitSlop. Each import keeps its own local copy, independent of the original document.
- Recents combines local and iCloud slops, with recently opened or changed documents first.
- Swipe a document to remove it quickly. Local slops offer Delete from This iPhone; iCloud slops offer Remove Download and Delete Everywhere.
- Remove Download keeps the document in iCloud and in Recents. Tap its cloud icon to download and open it again. Downloads with unsynced edits stay on the device until they are synced.

The iPhone app is available through [TestFlight](https://testflight.apple.com/join/F4qfCkgg). The 1.3.0 TestFlight build is distributed separately from the Mac and CLI release.
