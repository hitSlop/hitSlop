# hitSlop 1.1.0

## Mac app

### New

- Keep your slops in the Synced Library and sync them through iCloud with the iPhone TestFlight app using the same iCloud account.
- New from Template offers iCloud or On this Mac when iCloud is available. Move an existing local slop into the library with File ▸ Move to iCloud.

### Improved

- See when your library last synced, when a sync is in progress, and when hitSlop can't reach iCloud. Sync recovers from network errors and reports problems with individual documents.
- New Quick Checklist and Little Days documents have layouts made for phones, with larger touch targets, easier text entry, and forms that keep their actions within reach.
- Existing documents keep the app they were created with. Updated template layouts apply to new documents.

### Fixed

- Recents shows iCloud slops by name.
- Closing a document during sync no longer interrupts its upload.
- Text fields stay visible when the keyboard opens or the layout changes on iPhone.

## Authoring

- Adapt editors to the host with `getEnvironment()` and the `data-slop-platform`, `data-slop-device`, and `data-slop-layout` attributes. Phone editors receive safe-area and keyboard fit, a native Done button, and touch-friendly defaults.
- Add selection, impact, and notification feedback with the `haptics` API from `hitslop/svelte`. Feedback is silent on unsupported hosts or when disabled in settings.
- Use the shared transition helpers for sheets, dialogs, menus, and selects. See [Make it work on iPhone](https://hitslop.com/docs/guides/mobile/) for responsive layouts, haptics, and phone preview guidance.
