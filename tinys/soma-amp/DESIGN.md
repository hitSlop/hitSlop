# SomaAmp

Job: keep a favorite SomaFM station playing in a compact, skinnable receiver.

Classic Webamp main, EQ and playlist panels form the object. Preserve their
bitmap skins and pixel proportions. A two-row graphite rail adds SomaFM support, VIS,
skin import, museum discovery and reset; the native toolbar moves/closes the object.

The initial 275 × 470 layout extends to 725 × 470 for MilkDrop (the window is resizable so
the app can request the wider size). Panels stay docked.
Green readouts, muted gray supporting text and coral errors use theme tokens.
Keyboard focus stays visible. Webamp retains its classic compact controls.

Reopen paused. Reduce Motion disables MilkDrop and marquee animation without forgetting
that VIS was left open. Imported skins are attachments inside the document; Base clears the
reference and the file is removed when the document closes. When SomaFM cannot be reached
the rail and a coral notice say so; the bundled stream addresses are tried on play.

Export is a square receiver card with a prominent station display, static spectrum bars,
skin name and audio settings. The icon uses a dark display with green bars. Capture starts no streams.
