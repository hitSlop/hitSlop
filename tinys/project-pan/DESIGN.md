# Project Pan design

One job: see how close each product is to hitting pan, and which to use next.

The object is a rose-gold compact mirror seen open. The mirror glass carries the
title in marker script and the count of panned products; below it, a dark
palette tray holds one round pan per product in the shade it contains. A pan's
metal dish shows through from the centre outward, with area equal to how much is
used, so the pans visibly hollow. Select a pan to edit its name, brand, kind,
shade, percent left, date opened and period-after-opening; an expired product
that still has product in it is marked in words. Finished products move to an
"Empties" shelf of bare dishes.

Marker script (Marker Felt/Bradley Hand) for the title, system Avenir for text.
Bits UI owns the kind select and the percent slider. Pans are labelled buttons
that state their percent; shade is never the only signal. The export is the
open compact with every pan and the empties shelf, with no controls. The icon
is a rose-gold compact: mirror glass beside a half-used pan.
