# Scratch-Off List design

One job: turn a list of things to do into a small game of chance you actually finish.

The object is an instant-lottery ticket on a midnight-purple field: cream stock,
a magenta header band, gold lettering, a perforated rule and a grid of silver
foil tiles. Each unrevealed tile is a canvas the pointer rubs away; clearing
about half reveals the item, fading the foil and saving that the item is
revealed (partial scratches are presentation only). A "Reveal" button on every
tile does the same for keyboard use. A revealed item can be stamped done; the
stamp is a word and a mark, never color alone. Items you add yourself arrive
already revealed. "Re-cover all" turns the card back into foil for a new season.

Rounded system sans for text, marker for the title, tabular numbers for the
tally. Bits UI owns the done checkbox. Export shows static foil for unrevealed
tiles and the stamped card without controls. The icon is a ticket with six foil
tiles, two scratched to gold.
