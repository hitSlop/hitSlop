# Shape Lab

A developer's measuring instrument: warm grid paper, forest-green ink, orange corner
markers, clear orientation and actual input counts. It is deliberately unbundled.
The host owns clipping; the page never draws a fake window silhouette. Resize readouts
measure the mounted surface, not the requested size. Capture uses a separate rectangular
sheet and square icon. Temporary pointer/size/error state stays inside App.svelte.
