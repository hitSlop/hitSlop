# Pixel Art Studio

A pocket-console sprite desk for 16×16 drawing, fill, palettes, undo, and PNG export.

From the repository root:

```sh
bun slop dev examples/slops/pixel-art
bun slop build examples/slops/pixel-art
bun slop register examples/slops/pixel-art
```

Create a writable copy of the registered template before editing.
