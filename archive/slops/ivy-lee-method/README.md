# Ivy Lee Method

A strict six-item single-tasking ledger: finish item 1 before touching item 2, then roll unfinished work onto tomorrow’s six rows.

From the repository root:

```sh
bun slop dev examples/slops/ivy-lee-method
bun slop build examples/slops/ivy-lee-method
bun slop register examples/slops/ivy-lee-method
```

Create a writable copy of the registered template before editing.
