# Harada Method

The Open Window 64 chart: one core goal, eight themes, and sixty-four concrete actions on a single hand-ruled sheet.

From the repository root:

```sh
bun slop dev examples/slops/harada-method
bun slop build examples/slops/harada-method
bun slop register examples/slops/harada-method
```

Create a writable copy of the registered template before editing.
