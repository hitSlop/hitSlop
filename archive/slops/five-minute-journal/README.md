# Five Minute Journal

A paper morning-and-evening journal for three gratitudes, intentions, an affirmation, and dusk reflections.

From the repository root:

```sh
bun slop dev examples/slops/five-minute-journal
bun slop build examples/slops/five-minute-journal
bun slop register examples/slops/five-minute-journal
```

Create a writable copy of the registered template before editing.
