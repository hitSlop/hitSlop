# Side Quest

Your semester as a doodled notebook map. Courses are washi-taped trails,
assignments are quest nodes placed by due date, and exams are doodle-monster
bosses you study down one logged session at a time. Clearing quests earns
stickers you can slap anywhere on the map.

From the repository root:

```sh
bun slop dev examples/slops/side-quest
bun slop build examples/slops/side-quest
bun slop register examples/slops/side-quest
```

Create a writable copy of the registered template before editing.
