# Decision Balance

A compact weighing instrument: name a choice, add Pros and Cons, adjust their importance, and record your own verdict.

From the repository root:

```sh
bun slop dev examples/slops/pros-cons-sheet
bun slop build examples/slops/pros-cons-sheet
bun slop register examples/slops/pros-cons-sheet
```

Create a writable copy of the registered template before editing. Barlow Semibold is bundled with its [OFL license](assets/fonts/OFL.txt).
