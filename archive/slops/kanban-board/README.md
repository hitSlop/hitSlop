# Kanban Board

An anodized job-shop schedule board. Lanes are brushed metal rails, cards are
slotted paper work orders, and amber marks a lane over its work-in-progress limit.

From the repository root:

```sh
bun slop dev examples/slops/kanban-board
bun slop build examples/slops/kanban-board
bun slop register examples/slops/kanban-board
```

Create a writable copy of the registered template before editing.
