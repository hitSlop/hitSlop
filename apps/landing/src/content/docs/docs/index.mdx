---
title: hitSlop documentation
---

hitSlop keeps small apps and their documents together in portable files. Choose a template and create your own writable copy. Local Mac documents need no account. The iPhone TestFlight preview adds editing, creation, Files import and a Synced Library through iCloud. The ordinary Mac release keeps the library off until its Production rollout. Run named app actions or edit fields through the CLI, undo agent edits, share a saved copy, and export PNG/PDF. Apps can opt into native fullscreen; desktop windows can stay Always on Top.

Start with [create your first slop](./getting-started/) to build an app, or [document editing](./guides/edit-installed-data/) to work with an existing document. For terminal tasks, see [CLI workflows](./guides/cli-workflows/). [Availability](./availability/) covers release and preview availability, including [live sharing](./guides/live-sharing/).

Documents with a widget view can appear in Mac desktop widgets and, for library slops in the iPhone preview, Home Screen widgets.
See [icons, widgets, previews, and exports](./guides/icons-and-exports/) for setup,
refresh behavior and authoring the different views.

Apps can also capture photos and audio and transcribe saved recordings on-device on a
supported Mac. [Capabilities and permissions](./guides/capabilities/) explains what to
declare, when permission is requested, and how to keep the app useful when access is unavailable.
