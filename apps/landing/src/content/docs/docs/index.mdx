title: hitSlop documentation
---

hitSlop is a local macOS host for small apps and documents. No account required: choose a template, create a writable copy, and keep your work on your Mac. Run named app actions or edit fields through the CLI, undo agent edits, share a saved copy, and export PNG/PDF. Apps can opt into native fullscreen; desktop windows can stay Always on Top.

Start with [create your first slop](./getting-started/) to build an app, or [document editing](./guides/edit-installed-data/) to work with an existing document. For terminal tasks, see [CLI workflows](./guides/cli-workflows/). [Availability](./availability/) covers supported platforms and planned features.

Apps can also capture photos and audio and transcribe saved recordings on-device on a
supported Mac. [Capabilities and permissions](./guides/capabilities/) explains what to
declare, when permission is requested, and how to keep the app useful when access is unavailable.
