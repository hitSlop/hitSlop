---
title: Collaboration — coming soon
description: A preview of working together, and the ways you can share today.
---

Live collaboration is **coming soon**. The landing page shows an interactive concept with simulated participants; this release does not connect documents between people.

Today, work locally with your agent and export PNG or PDF to share a result. You can also close and copy a complete document for someone else to use independently. See [build and share](/docs/guides/build-and-share/).

You do not need hosting, database setup, or a server to use local documents. A future collaboration service will exchange updates between separate document replicas; it will not require multiple writers to open the same local file. No release date is announced.
