# MASH design

One job: play the paper fortune game and keep a card worth sharing.

The object is a ruled notebook page in blue gel pen with a red margin and spiral
coils down the left edge. Seven blocks (Home, Marry, Kids, Drive, Job, City,
Pet) each hold up to six editable options. "Spin the spiral" draws a pink
spiral of two to nine loops; that number is the count. The count walks every
option in a ring and strikes each nth one with a pen line, skipping a block
once one option is left. Survivors are highlighted in yellow and gathered on a
sticky "future card". The result is derived from the saved loop count and the
options, so it never drifts; editing options changes it, and spinning again
redraws it. The strike animation plays only on a fresh spin, never when a
document opens, and is skipped for reduced motion.

Marker Felt/Bradley Hand/Segoe Print handwriting, 32px ruled rhythm. Bits UI
is not needed: controls are native buttons and inputs. The export is the full
page with the future card and no controls. The icon is a torn notebook
corner with a pink spiral and the letters MASH.
