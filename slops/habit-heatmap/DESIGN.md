# Habit Heatmap

One job: mark the small things you want to repeat, then see the pattern over twelve weeks.

Preserve the archived object's plum shell, warm paper, rounded asymmetric panel,
twelve named habit colors led by mint/coral/butter/blue, and prominent streak readout. System Avenir
provides compact, readable text; tabular figures keep changing counts steady.
The initial rounded window is 620×480 and remains resizable. Tabs scroll when
habit names exceed available width; the document scrolls at smaller heights.

Each square is a labeled checkbox. A check mark carries completion independently
of color, the current day has an outline, and future days use dashed empty cells.
Names wrap in the active heading. Bits UI owns tab, dialog, radio and checkbox
behavior. Focus rings, keyboard access, and reduced motion are required.

The export is an ink-and-paper record of all habits in the current twelve-week
period, with no editing controls or nested scrolling. The icon is an abstract
colored grid on the same paper panel, not a representation of check-in data.
Public theme tokens cover shell, paper, ink, muted text, four colors, rule and focus.

Editing offers a four-column color palette and a separate removal action with
a Bits UI confirmation. Routine save indicators belong outside the authored UI.
